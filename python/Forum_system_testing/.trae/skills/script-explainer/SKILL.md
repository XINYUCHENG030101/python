# Script Explainer

用于解释自动化脚本的执行流程、每一步的作用，以及脚本中涉及的 Python 语法点。

## 适用场景

- 当用户希望理解一个自动化脚本整体在做什么时
- 当用户希望按步骤拆解脚本执行流程时
- 当用户希望知道某段 Python 脚本语法、函数或模块用途时
- 当用户贴出脚本并要求讲解执行顺序、输入输出或副作用时

## 目标

- 先解释脚本的整体目的
- 再按执行顺序拆解主要步骤
- 说明关键变量、函数、模块和外部依赖的作用
- 对涉及的 Python 语法提供通俗解释
- 提醒潜在风险，例如文件修改、网络请求、删除操作或权限要求

## 讲解方式

1. 先用一两句话概括脚本用途
2. 再按“开始 -> 处理 -> 输出/结果”的顺序解释流程
3. 遇到关键代码时，说明：
   - 这段代码做什么
   - 为什么这样写
   - 涉及哪些 Python 语法
4. 如果脚本较长，按模块或函数分段说明
5. 如果用户是初学者，优先使用简单语言，少用术语

## 输出建议

- 用分步骤方式解释
- 对关键函数、条件判断、循环、异常处理单独说明
- 必要时给出简化版伪代码，帮助用户建立整体理解
- 如果存在危险操作，明确提醒用户先备份或在测试环境运行

## 示例触发

- “帮我解释一下这个自动化脚本的流程”
- “这段 Python 自动化代码每一步在做什么？”
- “这个脚本为什么要这样写？里面的语法是什么意思？”
- “请按执行顺序讲解这份脚本”
